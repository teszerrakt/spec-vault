# Data Model: Centralized API Contract Platform

**Date**: 2026-01-23  
**Feature**: 001-api-contract-platform

## Overview

This platform uses GitHub as the primary storage layer - no traditional database. Data is stored as:
- **OpenAPI contracts**: YAML files in GitHub repository (or local filesystem in dev mode)
- **Session data**: Managed by NextAuth.js
- **Wizard state**: In-memory XState machines

## Entities

### APIContract

The central entity representing a complete OpenAPI specification.

```typescript
interface APIContract {
  filePath: string;              // Unique identifier, e.g., "contracts/payments/api.yaml"
  name: string;                  // From info.title
  version: string;               // From info.version
  description?: string;          // From info.description
  spec: OpenAPIObject;           // Full parsed OpenAPI 3.0+ specification
  rawYaml: string;               // Original YAML string
  lastModified: Date;            // From Git commit timestamp
  lastModifiedBy: string;        // From Git commit author
  commitSha: string;             // Current HEAD commit SHA
  isValid: boolean;
  validationErrors?: ValidationError[];
}

interface ValidationError {
  path: string;                  // JSON path to error location
  message: string;
  severity: 'error' | 'warning';
}
```

### ContractVersion

A point-in-time snapshot (retrieved on-demand from Git history).

```typescript
interface ContractVersion {
  contractPath: string;
  commitSha: string;
  timestamp: Date;
  author: string;
  message: string;
}
```

### ChangelogEntry

Generated by comparing two contract versions.

```typescript
interface ChangelogEntry {
  fromVersion: string;           // Commit SHA
  toVersion: string;             // Commit SHA
  contractPath: string;
  changes: Change[];
  summary: string;
  breakingChanges: boolean;
}

interface Change {
  type: 'added' | 'removed' | 'modified' | 'deprecated';
  category: 'endpoint' | 'parameter' | 'schema' | 'response' | 'security' | 'info';
  path: string;
  description: string;
  breaking: boolean;
}
```

### ImportSource

Ephemeral - stored only in wizard state during import flow.

```typescript
interface ImportSource {
  type: 'json' | 'csv' | 'excel' | 'image' | 'text';
  fileName?: string;
  content: string | ArrayBuffer;
}
```

### RepositoryConfig

User's selected GitHub repository configuration. The `owner` and `repo` fields
are bootstrapped from environment variables, while other settings can be 
stored in a config file within the connected repository.

```typescript
interface RepositoryConfig {
  owner: string;                 // From env: GITHUB_REPO_OWNER
  repo: string;                  // From env: GITHUB_REPO_NAME
  defaultBranch: string;         // From config file or env default
  contractsPath: string;         // Default: "contracts/"
}
```

### PlatformConfig

Platform configuration stored in the connected GitHub repository at
`.api-platform/config.json`. This allows administrators to change settings
without redeploying the application.

```typescript
interface PlatformConfig {
  version: number;               // Config schema version (currently 1)
  contractsPath: string;         // Default: "contracts/"
  defaultBranch: string;         // Default: "main"
}
```

### GitHubPermission

GitHub repository permission levels, used to determine administrator access.

```typescript
type GitHubPermission = 'admin' | 'maintain' | 'write' | 'triage' | 'read';

// A user is considered an admin if they have 'admin' permission on the 
// connected GitHub repository. This is checked via the GitHub API:
// GET /repos/{owner}/{repo}/collaborators/{username}/permission
```

## ContractRepository Interface

Abstracts contract persistence - GitHub (production) or Local filesystem (development).

```typescript
interface ContractRepository {
  listContracts(path?: string): Promise<APIContract[]>;
  getContract(filePath: string): Promise<APIContract>;
  saveContract(filePath: string, spec: OpenAPIObject, message: string): Promise<SaveResult>;
  deleteContract(filePath: string, message: string): Promise<void>;
  getHistory(filePath: string): Promise<ContractVersion[]>;
  createPullRequest?(options: PROptions): Promise<PullRequestResult>;
  
  readonly type: 'github' | 'local';
}

interface SaveResult {
  filePath: string;
  commitSha?: string;
  branch: string;
}

interface PROptions {
  title: string;
  body?: string;
  head: string;
  base: string;
}

interface PullRequestResult {
  number: number;
  url: string;
}
```

## State Machines

### Import Wizard

```
idle → selectSource → uploadFile → processing → preview → editing → saving → complete
                                                                          ↘ error
```

### Editor Wizard

```
loading → info → servers → paths → schemas → security → review → saving → complete
                                                                       ↘ error
```
